# Documentacao

Este repositório centraliza o plano do MVP para o site de desafios de corrida.

Arquivos:
- `docs/fase-1-descoberta-definicao.md`: decisoes funcionais e textos-base fechados na fase 1.
- `docs/plano-implantacao.md`: fases, cronograma, fluxo de entrega e publicacao.
- `docs/arquitetura-produto.md`: arquitetura recomendada, autenticacao, modelo de dados e diretrizes de interface.
- `docs/backlog-mvp.md`: backlog inicial com entregas tecnicas por frente.

Objetivo do MVP:
- publicar um site publico para consulta de desafios e ranking parcial;
- proteger qualquer cadastro com autenticacao;
- registrar desafios, equipes, participantes e resultados em banco Postgres;
- disponibilizar uma interface enxuta, mobile-first, com cara de app esportivo.
